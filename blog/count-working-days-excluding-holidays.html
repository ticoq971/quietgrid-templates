How to count working days between two dates, excluding holidays (Excel & Google Sheets)

To count leave days, project days or delivery times, you need working days, not calendar days. Excel and Google Sheets both have a built-in function for this.

The basic formula: NETWORKDAYS

=NETWORKDAYS(start_date, end_date, [holidays])
  • It counts Monday to Friday and includes both the start and end dates.
  • holidays is optional: a range of cells holding real dates to skip.

Example: Monday 5 October 2026 to Friday 16 October 2026:

FormulaResult
=NETWORKDAYS(DATE(2026,10,5), DATE(2026,10,16))10
Same range, with 12 Oct 2026 in the holiday list: =NETWORKDAYS(A2, B2, Holidays!A2:A30)9

Different weekends: NETWORKDAYS.INTL

If your weekend isn't Saturday and Sunday, use:

=NETWORKDAYS.INTL(start_date, end_date, weekend, [holidays])
weekend argumentDays off
1 (default)Saturday + Sunday
7Friday + Saturday
11Sunday only
"0000011"Custom string, Monday→Sunday, 1 = day off (here Sat + Sun)

The string version is handy for unusual schedules. For example, "0000111" means Friday, Saturday and Sunday off.

Half days

Neither function knows about half days. A simple pattern uses a "Half day?" column:

=IF(C2="Yes", 0.5, NETWORKDAYS(A2, B2, Holidays))

When is someone back? WORKDAY

To find the next working day after a leave ends:

=WORKDAY(end_date, 1, Holidays)

Example: leave ending Friday 3 July 2026 → returns Monday 6 July 2026.

Common mistakes

  • Dates stored as text. If =ISNUMBER(A2) returns FALSE, the cell isn't a real date. Re-enter it, or use DATEVALUE.
  • Holiday list with text or the wrong year. Holidays must be real dates in the right year.
  • Off-by-one. NETWORKDAYS counts both ends. Monday to Monday is 6 days, not 5.
  • Start after end gives a negative number. Add a check: =IF(B2<A2,"Check dates",NETWORKDAYS(A2,B2)).
