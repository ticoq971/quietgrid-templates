# Deploy to GitHub Pages (ticoq971/quietgrid-templates)
URL cible : https://ticoq971.github.io/quietgrid-templates/
Ce dossier est déjà un dépôt git local (branche main, commit prêt).
1. Créer le dépôt public vide `quietgrid-templates` sur https://github.com/new (sans README).
2. Pousser : `git remote add origin https://github.com/ticoq971/quietgrid-templates.git && git push -u origin main`
3. Settings → Pages → Source : "Deploy from a branch" → main / (root) → Save.
4. Restent à compléter : CONTACT-EMAIL, [FULL NAME], [SIRET], [ADDRESS] dans about.html / legal.html (hébergeur = GitHub, Inc.).
